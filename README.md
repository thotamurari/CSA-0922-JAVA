## Project Description

This assignment designs and implements an object-oriented Java model for a campus smart-parking system. It covers parking-slot allocation, ticket management, vehicle categories, fee calculation, inheritance, polymorphism, abstraction, encapsulation and testing.

## Assignment Tasks

- Task 01: Problem Analysis and Objects
- Task 02: Data Representation
- Task 03: Control Logic and Pseudocode
- Task 04: Classes, Objects and Constructors
- Task 05: Static Members and Object Life Cycle
- Task 06: Inheritance Hierarchy
- Task 07: Method Overriding
- Task 08: Polymorphism
- Task 09: Abstraction
- Task 10: Packages and Encapsulation
- Task 11: Implementation, Testing and Evaluation
- Task 12: Day-4 Design Challenge

## How to Compile and Run

Open the relevant task folder in the terminal.

For a standalone Java file:

```bash
javac ParkingFacility.java
java ParkingFacility
```

For `FeeDemo.java`:

```bash
javac FeeDemo.java
java FeeDemo
```

Use the correct filename and compile command for each task. Programs using packages may require compilation from the project root.
